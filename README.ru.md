# XrayWRT

[English](README.md)

XrayWRT добавляет в OpenWrt интерфейс LuCI и прозрачную маршрутизацию через прокси.
Используйте подписку Xray JSON или свою конфигурацию Xray JSON. Можно сохранить
несколько подписок, но активна только одна. YAML и ссылки вида `vless://` не
поддерживаются.

## Требования

- OpenWrt **25.12**, apk и firewall4/nftables; opkg не поддерживается.
- Поддерживаемый пакет ядра для 64-битного ARM, соответствующий выводу
  `cat /etc/apk/arch`.
- Рекомендуется **256 МБ RAM** и около **32 МБ свободной флеш-памяти** для
  установки. Для обновления ядра и geodata может потребоваться больше места;
  загружаемые файлы также занимают RAM.
- Проверенное устройство: Cudy WR3000S v1 с OpenWrt 25.12.6.
- Перед установкой удалите конфликтующие пакеты прокси и DNS. Установщик
  сообщит о конфликте. Используйте только один стек прокси.

## Установка

Выполните на роутере от root:

```sh
wget -qO- https://raw.githubusercontent.com/sweep7125/xraywrt/main/install.sh | sh
```

Выберите установку и язык. Установщик проверит контрольные суммы, установит
пакеты LuCI и зависимости, затем запустит `xraywrt core-update` для установки
отдельного пакета ядра. Если пакет ядра для архитектуры отсутствует, приложение
останется установленным, а служба выключенной. Для русского LuCI также установите
`luci-i18n-base-ru`.

1. Откройте **LuCI → Службы → XrayWRT → Подписка**, вставьте ссылку на подписку
   JSON и нажмите **«Подключить»**. Или введите свою конфигурацию в разделе
   **«Расширенные → Конфигурация Xray»**.
2. Проверьте **«Главная»** и настройте режим и правила в разделе **«Что через VPN»**.
3. На **«Главной»** запускайте и останавливайте службу, а также выбирайте сервер
   сервиса, если доступен выбор. Подробнее: [руководство](docs/user-guide.md).

## Обновление

Повторно запустите установщик для обновления пакетов приложения и установленного
ядра. Автоматического обновления ядра нет: используйте **«Обновления → Обновить
ядро»** или `xraywrt core-update`. Подписки и списки обновляются отдельно.
Перед обновлением проверьте свободную флеш-память и RAM. Остановленная служба
останется остановленной.

Пакеты приложения публикуются в `sweep7125/xraywrt`, а ядро — в
`sweep7125/xraywrt-core`. Автоматический выбор latest не включает prerelease.

## Если GitHub недоступен

Если заблокирован `raw.githubusercontent.com`, может помочь зеркало установщика
с привязкой к релизу. **Стороннее зеркало** — дополнительная точка доверия:
его скрипт выполняется от root. Пакеты и ядро оно не зеркалирует.
До публикации v0.1.1 ссылка закреплена на v0.1.0. Расположение релиза ядра
определяет установленное приложение; приложение v0.1.0 использует старое.

```sh
wget -qO- https://cdn.jsdelivr.net/gh/sweep7125/xraywrt@v0.1.0/install.sh | sh
```

Также можно перенести APK с доверенного компьютера. Перед копированием сверьте
пакеты приложения из `sweep7125/xraywrt` с `SHA256SUMS`, а пакет ядра из
`sweep7125/xraywrt-core` с `SHA256SUMS-core`. Контрольные
суммы проверяют целостность, но не подлинность релиза; пакеты не подписаны.
Установите зависимости на роутере:

```sh
apk update && apk add luci-base cgi-io ucode ucode-mod-fs nftables kmod-nft-tproxy curl ca-bundle
```

Затем следуйте [инструкции по установке из файлов](docs/user-guide.md#install-from-local-files).
Своё зеркало пакетов `XRAYWRT_RELEASE_URL` — дополнительная точка доверия;
обычный HTTP не защищает файл сумм. Ядро через это зеркало не загружается.

## Если пропал интернет

Откройте LuCI по адресу роутера, перейдите в **«Службы → XrayWRT → Главная»**
и нажмите **«Остановить»**. Или подключитесь по SSH:

```sh
service xraywrt stop
logread -e xraywrt
```

Остановка снимает перенаправление DNS и политику маршрутизации XrayWRT, возвращая
прямой доступ. Она действует до перезагрузки. Чтобы отключить автозапуск, снимите
флажок **«Расширенные → Служба → Запускать при загрузке»** или выполните
`service xraywrt disable`. Это не аварийная блокировка сети (kill switch).

## Удаление

Выполните `XRAYWRT_ACTION=remove sh install.sh` или удалите установленные пакеты:

```sh
apk del luci-i18n-xraywrt-ru luci-app-xraywrt xraywrt-core
```

Удаление останавливает службу и снимает её сетевую политику. Конфигурация и списки
сохраняются для переустановки; см. [руководство](docs/user-guide.md#remove).
